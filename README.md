# Shopping App

It is a simple imitation of a shopping website built with React, Typescript, Sass. 

# Let's start
You must have Node.js and Git before starting.

## First step - Download the project

### Go to the directory where you want to store the project:
```bash
git clone git@github.com:smile-code-mv/shopping-app.git
```
## Second step - Install Yarn

### Enter the shopping-app directory 
```bash
npm install yarn
```
And
```bash
yarn install
```

### If commands don't work
```bash
npm install --global yarn
```
And
```bash
yarn install
```

## How start
```bash
yarn dev
```
